# Mohammad Taufeeq — Personal Portfolio

A standalone, mobile-first personal portfolio and study-notes library. This project is intentionally separate from Northstar.

## Structure

- `index.html` — portfolio, education, learning areas, selected work and contact links
- `styles.css` — responsive design system and page styling
- `script.js` — accessible mobile navigation and dynamic copyright year
- `notes/index.html` — searchable and filterable study-notes library
- `notes/*.html` — individual study notes for DSA, DBMS, Digital Electronics and Python
- `notes/notes.js` — notes search and subject filters

## Run locally

Open `index.html` in a browser. No package installation or build step is required.

## Accuracy and content policy

The site uses only known profile facts. Learning areas are described as areas of study, not professional proficiency. The Team Alwan phishing-detection work is described as a hackathon learning project; it makes no unsupported claims about deployment, accuracy or impact. No contact form is included because no verified public email or form backend is configured. GitHub is the current public contact route.

The study notes are concise revision aids and should be checked against course material and instructor guidance.

## Hosting

The site is static and can be hosted on GitHub Pages or another static host. Do not add a canonical domain or publish until the final hosting URL has been selected and checked.
