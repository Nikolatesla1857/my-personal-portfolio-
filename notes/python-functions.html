Study note 04 · Python

Functions &
core collections.

Functions help organise a program into reusable pieces. Python's built-in collection types let you group values in different ways depending on how you need to use them.

Beginner levelProgramming basicsRevision note

1. Defining a function

Use the def keyword to define a function. Parameters receive input values, and return sends a result back to the caller.

def add(a, b):
    return a + b

result = add(4, 6)
print(result)  # 10

A function can also perform an action without returning a useful value explicitly. In that case, Python returns None.

2. Four useful collection types

List

A list is ordered and mutable. It allows duplicate values.

subjects = ["DSA", "DBMS", "Python"]
subjects.append("SQL")

Tuple

A tuple is ordered but immutable after creation. It can contain duplicate values.

coordinates = (12, 8)
print(coordinates[0])

Set

A set stores unique elements. It is useful when duplicate values are not needed.

unique_ids = {10, 20, 10}
print(unique_ids)  # {10, 20}

Dictionary

A dictionary stores key-value pairs. Keys are unique, and values are accessed using their keys.

student = {"name": "Asha", "semester": 3}
print(student["name"])

3. Quick comparison

  • List: ordered, mutable, duplicates allowed.
  • Tuple: ordered, immutable, duplicates allowed.
  • Set: unique elements; no positional indexing.
  • Dictionary: key-value mapping; keys are unique.
A useful habit: choose a collection based on the operation you need. Use a list for a sequence you may change, a tuple for a fixed group, a set for uniqueness, and a dictionary for lookup by key.

4. Quick practice

Write a function that takes a list of numbers and returns the largest value. Then try using a set to remove duplicates from the same list.
