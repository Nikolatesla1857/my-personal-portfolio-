Arrays in C:
the foundations.

An array stores multiple values of the same data type in a sequence. It gives each element an index, making it straightforward to access an item when you know its position.

Beginner levelCore conceptRevision note

1. What is an array?

An array is a collection of elements of the same type stored in contiguous memory locations. In C, the array has a fixed size when it is declared in the usual static form.

int marks[5] = {72, 81, 66, 90, 78};

Here, marks contains five integers. The first element is at index 0, and the last is at index 4.

2. Accessing elements

Use the array name followed by an index inside square brackets. Remember that C uses zero-based indexing.

printf("%d", marks[0]);  // first element
printf("%d", marks[4]);  // fifth element
Remember: An index outside the valid range is an out-of-bounds access. Always keep the valid index range in mind: 0 to size - 1.

3. Traversing an array

Traversal means visiting each element, commonly with a for loop.

#include <stdio.h>

int main(void) {
    int values[] = {4, 8, 12, 16, 20};
    int size = 5;

    for (int i = 0; i < size; i++) {
        printf("%d ", values[i]);
    }
    return 0;
}

4. Common operations

  • Access: Read an element using its index. This takes constant time, O(1).
  • Traversal: Visit all elements. This takes O(n) time.
  • Search: A simple linear search may inspect each element, so its worst-case time is O(n).
  • Insertion/deletion: Inserting or deleting in the middle usually requires shifting elements, which can take O(n) time.

5. Quick revision

  • All elements in a normal C array share the same data type.
  • Indexing starts at zero.
  • The declared array length determines the valid index range.
  • Direct indexed access is O(1); a full traversal is O(n).
